# Mark scheme

What each score means, per criterion. Use the nearest band and adjust by one
point either way. 5 is an average idea; 9 or 10 should be rare and needs
evidence behind it.

## Real problem

| Score | Meaning |
| --- | --- |
| 0–2 | No one has this problem, or it is invented to fit a technology. |
| 3–4 | A problem in theory, but no sign that people actually feel it. |
| 5–6 | A real but occasional annoyance for a broad group. |
| 7–8 | A clear, recurring problem for a specific group, easy to describe. |
| 9–10 | A painful problem people already spend time or money working around. |

## Worth solving

| Score | Meaning |
| --- | --- |
| 0–2 | Solving it changes nothing for anyone. |
| 3–4 | Nice to have; people are fine with the current workaround. |
| 5–6 | Saves some time or hassle now and then. |
| 7–8 | Saves real time, money or stress regularly. |
| 9–10 | Removes a blocker: without a fix, people lose money, grades, health or access. |

## Not already done

Mark against the evidence you found, not memory.

| Score | Meaning |
| --- | --- |
| 0–2 | A popular, mature tool already does exactly this. |
| 3–4 | Several tools do most of it; this would be one more. |
| 5–6 | Similar tools exist but miss a meaningful part of the idea. |
| 7–8 | Only small or abandoned projects come close. |
| 9–10 | Nothing similar turned up in a reasonable search. |

## Something new

| Score | Meaning |
| --- | --- |
| 0–2 | A copy of an existing product with no change. |
| 3–4 | An existing product for a slightly different audience. |
| 5–6 | A familiar idea with one fresh twist (interface, audience, channel). |
| 7–8 | A new combination or method that changes how the problem is solved. |
| 9–10 | A genuinely new approach or insight that others would copy. |

## Within reach

Use the weeks available and the team's skills.

| Score | Meaning |
| --- | --- |
| 0–2 | Needs skills, data, hardware or permissions the team does not have. |
| 3–4 | Possible only with a lot of new learning or a much longer timeline. |
| 5–6 | A cut-down version fits the time if the scope is narrowed. |
| 7–8 | A working first version fits the time with the team's skills. |
| 9–10 | Comfortably buildable, with time left to polish and test with users. |

## Someone wants it

| Score | Meaning |
| --- | --- |
| 0–2 | No identifiable user. |
| 3–4 | "Everyone" or a vague group; no reason to believe they would switch. |
| 5–6 | A clear group, but unclear whether they would use or pay for it. |
| 7–8 | A specific group with an obvious reason to use it, reachable by the team. |
| 9–10 | People are already asking for it, or would pay for it today. |
